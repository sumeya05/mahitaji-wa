How photos reach products

  • Name each file after the item code: BID283.jpg attaches to product BID283 (case does not matter; bid283_front.jpg works too).
  • You can select many files at once, or upload one or more .zip archives of photos.
  • Files whose name matches no item code are still saved to the images folder, so a CSV import can point at them: give the image column the file name (bd001.jpg) or a web address (https://…/photo.jpg, downloaded for you). A blank cell keeps the current photo.
  • Accepted: JPG, PNG, WebP, GIF up to 8 MB each; large photos are shrunk to 1600 px.
